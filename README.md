# Daily Tracker

This repository contains the source code for an Android app that tracks plays of daily games such as Wordle.

Using this app, you can track which games you've played already on a given day and which you have yet to play. You can track your streak, get notifications for unplayed games, and also record past scores.

A number of popular daily games are supported out-of-the-box, and some support exists for user-defined games as well.

## Recording Scores

In order to record a score for a daily game in Daily Tracker, you can either copy and paste the score into the game details page, or you can share it to the Daily Tracker share target. In the latter case, Daily Tracker will try to automatically determine the game and the date, or prompt you if it can't be automatically determined.
